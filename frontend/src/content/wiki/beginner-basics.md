# 新手村：零基础 AI 概念扫盲

> 从来没接触过 AI 开发？这一页就是为你准备的。不讲公式、不堆黑话，每个概念都配一个生活里的比喻。看完这页，你就能听懂这个网站在讲什么。

## LLM（大语言模型）是什么

![AI 大模型核心概念图解](/wiki/ai-concepts.png)

LLM（Large Language Model，大语言模型）是一个"读了半个互联网"的程序。它从海量文本里学会了语言的规律和世界的常识，能听懂你说的话，也能写出像人话的回答。

几个关键直觉：

- **它很大**：内部有数十亿到数千亿个"参数"（可以理解为神经连接的强度）。规模大到一定程度后，它会"涌现"出没人教过它的能力
- **它是通用的**：同一个模型能聊天、写代码、翻译、总结——不需要为每个任务单独训练
- **它不是数据库**：它是在"预测下一个最合理的词"，不是在做精确检索。所以它会一本正经地胡说八道（这叫"幻觉"），重要内容要自己核实

常见的模型有：DeepSeek、Kimi、通义千问、智谱 GLM（国内直接可用）；ChatGPT、Claude、Gemini（海外）。

## Token 与上下文窗口

**Token** 是模型读文字的"最小单位"，可以粗略理解为"字/词碎片"。中文大约 1~1.6 个字 = 1 个 token。它重要在两个地方：

- **算钱**：API 按 token 计费（输入的 token 和输出的 token 都算）
- **算记忆**：模型一次能处理的内容总量有上限

**上下文窗口（Context Window）** 就是这个上限——你的输入 + 它的回答 + 中间思考，全部加起来不能超过这个数。超出就会"忘事"或报错。这就是为什么长对话里 AI 会突然忘记你开头说的话。

## Prompt（提示词）：怎么说话 AI 才听得懂

Prompt 就是你发给 AI 的那段话本身。同一个 AI，问法不同，答案质量天差地别。三个基本原则：

1. **指令明确**：不说"帮我写点东西"，而说"写一篇 300 字的新能源汽车博客引言，面向普通读者，语气积极"
2. **给背景**："你是一位经验丰富的项目经理，正在为初创公司制定上线计划"——角色和上下文会显著改变回答质量
3. **定格式**：明确要列表、表格还是 JSON；复杂任务用"第一步…第二步…"拆开说

一个万能起手式：**角色 + 任务 + 要求 + 格式**。

## Agent / Skill / Harness

这三个词经常一起出现，用"装修队"来比喻：

![AI Agent 智能体完整架构](/wiki/agent-arch.png)

- **LLM = 一个博学的顾问**：你问它答，一问一答，答完就忘
- **Agent（智能体）= 包工头**：你给它一个目标（"帮我分析上周销售数据并出报告"），它自己会拆步骤、查数据、调用工具、多步执行，直到把活干完。它有记忆、能规划、会动手
- **Skill = 工具箱里的工具**：给 Agent 装的扩展能力，比如"联网搜索""执行代码""读写文件"。装得越多，Agent 能干的活越杂
- **Harness（运行框架）= 施工现场的管理系统**：负责调度工具、记录状态、错误重试、评估效果——让包工头有组织地干活，而不是自由发挥

这个网站练的就是：从调用 LLM 开始，一步步学会造出自己的 Agent。

## API Key 是什么

API Key 是你调用模型厂商服务的"钥匙 + 门禁卡"：一长串字符（通常以 `sk-` 开头）。它证明"这个请求是你发的"，厂商按它记账收费。

几个要点：

- **它等于钱**：泄露了别人就能花你的额度，所以永远不要把它提交进 git、发给别人、写进公开页面
- **本站的用法**：点右上角 ⚙️ 打开 AI 配置，把你的 DeepSeek Key 填进去——只存在你自己浏览器里，不会上传。云端版没填也能用（有站点试用额度，限量）
- **去哪里拿**：DeepSeek 开放平台注册 → 创建 API Key，新用户通常有免费额度

## Vibe Coding（氛围编程）

Vibe Coding 是 2025 年以来流行的开发方式：**你不写代码，你描述想要什么，AI 来写**。你的角色从"码农"变成"指挥官 + 审校员"——说清楚意图、检查 AI 的产出、纠正方向。

它的爽点：原型开发速度提升一个数量级，不会语法也能做出能跑的东西。
它的代价：AI 写的代码你要看得懂、审得住——**这正是修炼的意义**。

主流工具（2026 年）：

| 工具 | 形态 | 特点 |
|---|---|---|
| **Kimi Code** | 命令行 Agent | 国内可直接用，中文理解好，本站作者就在用它开发本站 |
| **Claude Code** | 命令行 Agent | 业界标杆之一，长上下文强（需海外网络） |
| **Codex CLI** | 命令行 Agent | OpenAI 出品（需海外网络） |
| **Cursor** | AI 原生编辑器 | 图形界面，上手门槛最低 |
| **GitHub Copilot** | 编辑器插件 | 代码补全老牌选手 |
| **通义灵码** | 编辑器插件 | 国产，中文注释理解好，企业合规友好 |

给新手的建议：先随便挑一个装起来（国内用户推荐 Kimi Code 或通义灵码，零网络门槛），让它帮你写一个小工具试试手感。
